# DictaMute 0.0.107-alpha

This is the planned first public alpha release of DictaMute.

> Publication is not yet approved. This file is the release-note source used by the release workflow once the release request is armed.

## What DictaMute does

DictaMute is a free, open-source Windows utility that automatically ducks, mutes or pauses selected applications when configured microphone activity exceeds a chosen threshold.

## Highlights

- configurable X source applications and Y target applications;
- Duck, Mute and Pause reactions;
- configurable microphone signal threshold and hold time;
- profiles with independent active/disabled state;
- global hotkeys and notification-area operation;
- explicit media-session assignment for ambiguous Pause targets;
- local JSON configuration and diagnostic logging;
- DictaMute SVG/window/tray branding;
- Windows 10/11 x64 self-contained package.

## Important behavior

DictaMute does not perform speech recognition. A threshold can be crossed by speech, keyboard noise or other sound reaching the configured microphone.

Pause depends on a uniquely matched Windows media session. If DictaMute cannot identify one safely, it falls back to Duck.

## Privacy

The current implementation uses audio session state and level metering; it does not create a raw microphone recording stream and does not include telemetry, behavioral analytics or automatic network update checks.

See `PRIVACY.md`.

## Known limitations

- application/session behavior varies between software;
- protected, elevated, exclusive or unusual audio paths may not behave as expected;
- media-session identifiers can change across application versions;
- signal threshold is not a voice classifier;
- broad compatibility/performance testing is still limited;
- this alpha should be tested with non-critical workflows before extended reliance.

## System requirements

- Windows 10 build 17763 or later, or Windows 11;
- x64 for the official initial binary package.

## Install

Extract the official ZIP to a user-controlled directory and start `DictaMute.exe`.

No separate .NET runtime is required by the self-contained package.

## Remove

Exit DictaMute from the notification area and remove its program files.

Optional local settings/log cleanup:

`%LOCALAPPDATA%\DictaMute\`

See `PRIVACY.md` before deleting settings you may want to preserve.

## Integrity

Verify the official ZIP against the published `SHA256SUMS.txt`.
