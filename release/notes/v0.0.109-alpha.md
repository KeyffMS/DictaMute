# DictaMute 0.0.109-alpha

This is the planned first public alpha release of DictaMute.

> Publication is not yet approved. This file is the release-note source used by the release workflow once the release request is armed.

## Changes since 0.0.108 development build

### Reliable explicit source selection

- the X source selector now keeps all currently known non-expired microphone sessions visible instead of showing only sessions active at the exact UI snapshot;
- each microphone candidate is labeled as active or inactive;
- Ctrl+Alt+X now prefers the actual active microphone-owning application instead of blindly adding the foreground text receiver;
- when several applications use the microphone, DictaMute uses the selected microphone candidate or a matching foreground candidate; otherwise it refuses to guess;
- Ctrl+Alt+Y continues to use the foreground application, which is appropriate for selecting a playback target.

This specifically improves Windows Win+H dictation and similar workflows where the process owning the microphone differs from the application receiving text.

## Microphone gate stability

The 0.0.108 anti-chatter changes remain included:

- 60% release-threshold hysteresis while the gate is already open;
- faster playback-session refresh while the gate is active;
- OPEN/CLOSE gate diagnostics in the local log.

## Current release status

No official DictaMute binary has been published yet. Temporary GitHub Actions artifacts are not official downloads.

## System requirements

- Windows 10 build 17763 or later, or Windows 11;
- x64 for the planned initial official package.
